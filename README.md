# Decentralized-P2P-Chat-File-Sharing
Serverless P2P communication platform using WebRTC, WebSockets, and Helia (IPFS), enabling direct browser-to-browser messaging and decentralized file sharing without centralized data storage.

Ways to use it:
1. Download all the files and put it in a single folder.
2. Take the folder location and open it in cmd and type 'npm install' in order to create the node_modules folder.
3. Open two command prompts on the folder location and type these two commands: npm run signal and npm run dev.
4. Select the local host site from the cmd to access the frontend.
5. Use the same link to connect multiple devices together.

TIP: You can even kill the starting server: npm run signal midway during the conversation just to see the interdependence of the decentralized network from the central command.
